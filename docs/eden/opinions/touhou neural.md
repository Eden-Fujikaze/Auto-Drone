## Goal
Either via RL or ML have a program that can play any level with no user information
## Steps
1. Choose either memory reading or display byte interpretation
2. Choose a game to use it on and make a save state system
3. Train milions of generations
## Troubles
If memory reading is chosen - data needs to be labeled by hand (Thousands of samples) OR via display needs optimizations to process frames in time.
Memory reading will be consistent while display will probably never beat a new level - just the ones it learned.
A lot of research on wiring neurals and feeding it training data.
